# 场景一页纸合集（SCENE SCORECARDS，2026-10-19）

每个流量模式/场景一页，六组指标，逐条给 PASS/FAIL 与实测数字。
工具：`CODE/work/WP-T1-SCENE-CAL/scene_scorecard.py`（可对任意 run 重算）。

**判据（括号内为阈值）**

| 检查 | 含义 | 阈值 |
|---|---|---|
| 积压存在 | 真值>0 的候选行占比 | ≥20% |
| 候选有差异 | 同一次决策内候选真值有差异的比例 | ≥50% |
| **完美状态能翻转决策** | 把状态项换成真值后，选中的候选会不会变 | **≥5%** |
| 积压可被观测 | 真值>0 却被最新观测漏掉的比例 | ≤20% |
| 接入不主导 | 接入等待总和 | =0 |
| 无溢出/超期 | ISL/holding/access 溢出 与 超期 | =0 |
| 可达性不混淆 | NO_ROUTE | =0 |
| 两臂预测/决策确实分叉 | 仅在两臂对照时 | ≥1% |

**读法**：只有 C（h1 热场景）在「完美状态能翻转决策」上是两位数（10.48%），
其余场景即使给它完美状态也翻不动——A 因为候选普遍无法比较、B 因为接入主导、
D/E 因为 OD 一多差异就被摊薄。F 做到了臂在预测上分叉（6.53%），但决策仍不动（0.00%）。
