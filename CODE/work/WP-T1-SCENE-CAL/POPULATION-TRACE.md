## 覆盖过滤（先于抽样的场景约束）

用现有 Constellation（96 星 / 12 面 / 800 km / 53° / 仰角 >10°）在发射窗 [2.00, 2.35] s 内取 8 个时刻，
逐格求最小可见星数。**368 个格（占 4 938 的 7.45%，人口 2.345e8）在窗口内任何时刻都看不到卫星**——
这些格接入不了，若留在样本里，测到的是星座覆盖空洞而不是路由。

**处理：从抽样宇宙中剔除，并报告被剔除的人口。** 这不是按性能挑样本：
判定只用几何可见性，与任何业务结果无关。剩余 **4 570 格**参与抽样。

## 抽样（`population_od_program.py`）

- **源、目的两端都按人口加权**：别名法（复用 `leo_sim.trace.VoseAlias`）分别抽源格与目的格，
  去掉同格与重复对，取前 96 对；每对权重 = `p(源) × p(目的)`，再整体归一化。
- 固定 seed **20261019**；程序 digest 与 CSV sha256 一并记录。
- **实际入册 93 对**：生成后有 3 对在 0.35 s 窗口内一个包都没产生，**删掉并重新归一化后重生成**，
  而不是把“声明了却没发生”的 OD 留在表里（记录在 report 的 `sampling.dropped_zero_packet_ods`）。

## 格内位置（不许全部落格心）

- 2° 格约 222 km。程序为每个入选格声明 `intra_cell`：用 0.25° 原生像素把该格切成 8×8 子格，
  按子格人口归一化；**每个包**的源点与目的点各自抽一个子格位置。
- 实测 **149 个格、8 477 个子格**。
- **落在格心（±1e-9）的包：0 / 5 827 = 0.00%**。

## 人口位置 → 接入卫星

离线几何复算：对每个入选格的全部子格落点，在 [2.00, 2.35] s 内每 0.05 s 求可见星集合与最大仰角星。

| 指标 | 值 |
|---|---:|
| 覆盖格 | 149 |
| 可见星数中位 | **2** |
| 单格内不同子格落点得到不同最佳星 | **25 / 149 格** |
| 窗口内最佳星发生切换 | **7 / 149 格** |
| 单格最多不同最佳星数 | 2 |

→ 这是**格心化的反证**：把整格人口钉在格心会抹掉 25 个格的接入异质性。
明细在 `population_access_map_2deg_20261019.csv`。

## 尚未完成 / 限制（必须写清）

- 映射是**离线几何复算**（最大仰角规则），不是 kernel 接入状态机（含滞后/驻留/租约）的逐决策复算；
  需在人口探针 run 后用 `result.access` 与逐包 uplink 事件对照才能宣称一致。
- **“接入等待不主导”尚未用真实数据证明**：需读人口 run 的 access 统计并与 ISL 队列面积比较。
- 负载 200 Mbps 是为让整个 0.35 s 窗口装进 6 000 包量级；**不是标定负载**，结论只能按探针级负载陈述。
