## 抽样（`population_od_program.py`）

- **源、目的两端都按人口加权**：别名法（复用 `leo_sim.trace.VoseAlias`）分别抽源格与目的格，
  去掉同格、去掉重复对，取前 96 对；每对的权重 = `p(源) × p(目的)`，再整体归一化。
- 抽样用固定 seed **20261019**，程序 digest 与 trace sha256 一并记录，可复现。
- **实际入册 89 对**：生成后发现 7 对在 0.35 s 窗口内一个包都没产生。
  处理方式是**删掉这 7 对并重新归一化后重新生成**，而不是把“声明了却没发生”的 OD 留在表格里。
  被删的 7 对与原因写进 `population_trace_program_2deg_20261019-report.json` 的
  `sampling.dropped_zero_packet_ods`。

## 格内位置（不许全部落格心）

- 2° 格约 222 km。程序为每个入选格声明 `intra_cell`：用 0.25° 原生像素把该格切成 8×8 子格，
  按各子格人口归一化；**每个包**的源点与目的点各自抽一个子格位置（`scene_trace_program._draw_intra`）。
- 实测 **151 个格、8 819 个子格**。
- **落在格心（±1e-9）的包：0 / 6 030 = 0.00%**。

## 人口位置 → 接入卫星

用**现有 Constellation 几何**（96 星 / 12 面 / 800 km / 53° / 仰角 >10°）离线复算：
对每个入选格的每一个子格落点，在发射窗口 [2.00, 2.35] s 内每 0.05 s 求可见星集合与最大仰角星。

| 指标 | 值 |
|---|---:|
| 覆盖格 | 151 |
| 可见星数中位 | **2** |
| 单格内不同子格落点得到不同最佳星 | **25 / 151 格** |
| 窗口内最佳星发生切换 | **8 / 151 格** |
| 单格最多不同最佳星数 | 3 |

→ 这两行是**格心化的反证**：把整格人口钉在格心会抹掉 25 个格的接入异质性。
明细在 `population_access_map_2deg_20261019.csv`。

## 尚未完成 / 限制（必须写清）

- 上述映射是**离线几何复算**（最大仰角规则），不是 kernel 内部接入状态机（含滞后/驻留/租约）的逐决策复算；
  两者在探针运行后按 `result.access` 与逐包 uplink 事件对照，才能宣称一致。
- **“接入等待不主导”尚未用真实数据证明**：需要在人口探针 run 里读 `access` 统计
  （等待时长/等待队列/在停等待数）并与 ISL 队列面积比较。本地无该数据，不能先写结论。
- 负载 200 Mbps 是为让整个 0.35 s 窗口放进 6 000 包量级的探针规模；
  **它不是标定负载**，人口性能结论只能按“探针级负载”陈述，不能与 1 116 Mbps 的格直接比数。
