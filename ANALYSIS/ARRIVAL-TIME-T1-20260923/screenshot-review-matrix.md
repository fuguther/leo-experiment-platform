## 2. 定位声明（§1A 原文对齐）

本项目**不是**全网中央流量矩阵分配、预计算固定路径或 TE 优化。当前卫星依据**合法本地/一跳已到达信息**，为一个包选择下一跳；后续节点按**相同在线策略**重新决策。TE 规划器即使作为诊断组存在，**不进入在线方案的状态、训练标签或公平主比较**。

→ 该声明与 00e 的信息权限表、01-formal-model 的 estimand 定义一致。

## 3. 两段时间错位必须拆开（§1A.2 落地）

实际观察的是邻居在 t_m 测得、t_rx 才到达本星的字段；目标包在 t_a 抵达下一跳。

| 段 | 定义 | 平台对应 | 覆盖状态 |
|---|---|---|---|
| **陈旧补偿** | S_j(t_m) → S_j(t_0)：过去测量 → 当前决策开始 | 信息权限中的 age_s / generated_at / received_at + **refresh 观测模式** | ✅ E1 已验（refresh：t_measure == t_decision_commit） |
| **行动生效补偿** | S_j(t_0) → S_j(t_a)：决策后计算、本星排队、发送、传播 | t_decision_commit → t_local_queue_enter → t_service_start → t_service_finish → t_peer_arrival | ✅ E1 已验单调性与各段固定点（2.36e-14 / 1.50e-08） |
| **完整时错** | S_j(t_m) → S_j(t_a)：既含控制消息年龄，也含候选 ETA | 需 O3（各候选自身到达时刻真值）注入 | ⏳ **待 E3**（这正是 E3 的主比较对象） |

**强制后果**：对每一候选，记录三段在**实际竞争资源**上的状态/等待成本差，而不仅是不同候选之间的几何传播差；O0/O1/O2/O3 的主比较必须能解释"是旧信息问题还是候选到达时刻问题"。

→ 已在 03-preregistration.md §2 的对照臂表与 04-counterfactual-validation.md §6 的四象限测试（真实ETA×真值队列 / 估计ETA×真值队列 / 真实ETA×预测队列 / 估计ETA×预测队列）中落实。

## 4. 三因素可识别性（§5A 与 §1A 观点 5 的衔接）

| 轴 | 独立变化量 | 必须保持不变 | 实测可识别性 |
|---|---|---|---|
| F1 背景流量 | demand.offered_mbps | ISL 容量/速率模式、调度、几何、控制信令 | ✅ 结果层：改 offered 不动 F2 记账（0.0），仅改变同链路 p95 排队（0.167 → 0.600 s） |
| F2 排队转发效率 | execution.node_process_delay_s | 名义 PHY 速率、外生流量、几何、包大小 | ✅ 与 PHY 结构分离；线性（3× → 3.00×）；**但必须传 node_spans_by_pid**，否则静默记成 decision_compute |
| F3 链路带宽 | links.isl_rate_mbps（constant 模式） | 外生包序列、调度/处理开销、几何、控制规则 | ✅ 结果层：改 isl_rate 不动 F2 记账；同链路 p95 排队随带宽变化（0.160–0.556 s） |

**禁止**：若某轴只能靠降 isl_rate_mbps 实现，即已属 F3——本项目的 F2 走的是 execution.node_process_delay_s（节点处理时延），**结构上独立于 PHY**。
