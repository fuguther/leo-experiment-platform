## 4. 预注册假设与判据（写在结果之前）

记号：τ = AoI（决策时刻 − 状态测量时刻）；m = 同一策略 J 下 1↔2 名候选的 truth margin；
flip = committed action ≠ 用 truth work-ahead 重算的 same-policy action；
R = 上述替换后的 truth-J regret（≥0）；Γ = L·τ/m（L = |d(ΔJ_ab)/dt|，单位 s/s）。

- **H0（负对照）**：`geometry` 的 flip rate 在构造上=0（J 不含队列状态）；高/低负载都应 ≈0。
- **H1（高敏感）**：`queue_greedy` 在 high+burst+adv=1 s 下 flip rate 与 regret 高于 geometry；
  低负载 cell 中两者差距收缩到接近 0。
- **H2（迟滞）**：同 cell 下 `queue_greedy_hysteresis` 的**切换率**低于 greedy，
  flip rate 不高于 greedy（允许代价：E2E 或队列面积略升）。
- **H3（平滑）**：`queue_greedy_ewma` 的 flip rate 低于 greedy，但高于 hysteresis（预期介于两者之间）。
- **H4（强同步）**：`p2-sync-*` 的 τ 显著低于 `p1-high-*`（p50 从 ~百 ms 降到 ~传播+半周期量级），
  greedy 的 flip rate 随之下降；若 flip rate 与 regret 仍与 p1-high 同量级或更高，
  则 stale state 具有超出"广告频率"的结构性（这是要报告的**反证**方向）。
- **H5（Γ 关系）**：Γ<1 的样本 flip rate 显著低于 Γ≳1 的样本；单调性用分箱表报告，
  不强行拟合理论曲线。若单调关系不出现，如实报告"当前 regime 下 Γ 无预测力"。
- **H6（方向/持续性）**：flip 的方向偏置与连续同向 run 长度要报告；若后悔主要来自
  绕行而非队列，报告该机制解释（与 O3/O6 的历史发现对照）。

**判定规则**：报告所有 12 个 cell 的实际值，含零效应/反例。任何"策略 A 更好"的结论必须
同时满足：配对 E2E 差的方向与 flip/regret 的方向一致，且在多 cell 中不反转；单 cell 差异不作强结论。
pilot 阶段（本轮）不预注册显著性阈值（不做 p 值主张），只报告分布与配对差。

## 7. 指标定义（分析器实现，见 sq_policy_analyze.py）

- AoI：τ = t_commit − measured_at（chosen 候选）；分解 `gen→recv`、`recv→decision`、`decision→arrival`。
- margin：J_used 的 1↔2 名差；以及 J_truth 的 truth margin。
- flip：仅统计 ≥2 个有有效 truth 候选的 forward 决策；P(flip)。
- regret R、错误持续 W、L、Γ、网络 E2E/交付/队列面积/吞吐/跳数、
  控制面 bits/packets/时延/服务时间占比。
- 跨策略配对：同 `trace-manifest.source_trace_sha256` 的 cell，按 pid 配对都 DELIVERED 的包。
